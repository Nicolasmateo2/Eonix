# Eonix (Flutter)

Eonix es una app móvil de educación financiera y simulación de decisiones. Este repositorio fue migrado de React a Flutter.

## Requisitos

- Flutter SDK instalado

## Comandos

```bash
flutter pub get
flutter run
```

Para regenerar las carpetas de plataforma (android/ios/web/etc.) si no existen:

```bash
flutter create .
```
